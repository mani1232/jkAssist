# AIHome

**AIHome** — це розумний ШІ-асистент (чат-бот) для мешканців житлових комплексів (ЖК), створений на базі Kotlin Multiplatform. Проєкт складається з вебклієнта на Compose Multiplatform (Wasm) та сервера на Ktor, який використовує Google Gemini для обробки природної мови та маршрутизації запитів.

## ✨ Ключові можливості

* **Розумний чат-бот**: Обробка запитів мешканців (перевірка відключень світла/води, створення заявок на ремонт).
* **Інтеграція зі ШІ**: Використання бібліотеки `koog-agents` та моделей Google Gemini для інтелектуального діалогу зі збереженням контексту (пам'ять сесій).
* **Переведення на оператора**: Якщо ШІ не може розв'язати проблему (або в екстрених ситуаціях), чат безшовно переводиться на живого оператора.
* **Консоль оператора**: Вбудована CLI-консоль на сервері для спілкування з користувачами, які очікують відповіді живої людини. **Це тимчасове рішення** для демонстрації роботи системи, яке в майбутньому можна легко замінити на повноцінну графічну адмін-панель або інтеграцію з вашою існуючою CRM.
* **WebAssembly (Wasm) Frontend**: Сучасний, швидкий та чуйний інтерфейс, написаний на Compose Multiplatform.
* **PWA та Push-сповіщення**: Підтримка встановлення застосунку на пристрій (Progressive Web App) та отримання фонових push-сповіщень від оператора чи ШІ.
* **Real-time взаємодія**: Зв'язок між клієнтом та сервером працює через WebSockets.

## 🛠 Стек технологій

* **Мова**: Kotlin
* **Архітектура**: Kotlin Multiplatform (Web, Server, Shared)
* **Frontend**: Compose Multiplatform (Wasm target), Material 3, Service Workers (PWA)
* **Backend**: Ktor (WebSockets, Content Negotiation, CORS, WebPush)
* **AI / Агенти**: Koog Agents + Google Gemini Models
* **Серіалізація**: `kotlinx-serialization-json`
* **Дата/Час**: `kotlinx-datetime`
* **CI/CD**: GitHub Actions (Docker/GHCR, GitHub Pages)

## 📂 Структура проєкту

* **`/composeApp`**: Клієнтська частина. Містить UI чату, логіку PWA та мережевий клієнт для WebSocket. Збирається у Wasm-застосунок для браузера.
* **`/server`**: Серверна частина (Ktor).
  * Керування ШІ-агентом та системними промптами.
  * Керування сесіями та історією (збереження у файлову систему).
  * Інструменти агента: отримання профілю, перевірка відключень, створення заявок.
  * Мок-база даних (`MockDatabase.kt`).
  * Відправка WebPush-сповіщень та консоль оператора.
* **`/shared`**: Спільний код для клієнта та сервера (моделі DTO, події WebSockets).

## 🚀 Запуск проєкту

### Попередні вимоги
* **JDK 26** (відповідно до налаштувань проєкту).
* Отриманий API-ключ для Google Gemini (`GEMINI_API_KEY`).
* VAPID Private Key для роботи Push-сповіщень (`PRIVATE_KEY`).

> **⚠️ ВАЖЛИВО: Налаштування Push-сповіщень**
> У поточній версії проєкту публічний VAPID-ключ для Push-сповіщень жорстко вшитий у код як приклад. **Перед використанням у продакшені вам необхідно згенерувати власну пару ключів (Public/Private VAPID keys) та замінити публічний ключ у наступних файлах**:
> 1. `composeApp/src/webMain/resources/registerServiceWorker.js`
> 2. `composeApp/src/webMain/kotlin/cc/worldmandia/jkassist/ui/App.kt`
> 3. `server/src/main/kotlin/cc/worldmandia/jkassist/service/WebPushService.kt`

### Запуск сервера
Для роботи ШІ-агента та системи сповіщень необхідно задати змінні середовища.

**Linux / macOS:**
```bash
export GEMINI_API_KEY="ваш-ключ-тут"
export PRIVATE_KEY="ваш-vapid-private-key-тут"
./gradlew :server:run
